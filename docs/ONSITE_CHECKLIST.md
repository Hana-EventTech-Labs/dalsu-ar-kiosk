# 현장 설치·검증 체크리스트 (Smart-81D 실장비)

개발 PC에는 프린터가 없어 **실장비 인쇄는 아래 절차로 현장(또는 사무실 프린터 연결 PC)에서 검증**합니다.
모든 항목을 체크한 뒤 운영에 들어갑니다.

## A. 설치 (10분)
- [ ] **설치형 사용**: GitHub Release 의 `DalsuARKiosk-Setup-X.Y.Z.exe` 실행(원클릭, 사용자별). 이후 새 버전은 대기 화면에서 자동 적용된다.
      설정·출력·로그는 `문서\DalsuARKiosk\` 에 생긴다 (config.json 도 여기). zip 으로 풀어 쓰면 자동 업데이트가 안 된다.
- [ ] 인터넷 연결 확인 (자동 업데이트용). 없어도 앱은 정상 동작 — 로그에 '업데이트 확인 실패'만 남는다.
- [ ] Node.js 22 LTS 설치 (`node -v`)
- [ ] .NET 8 Desktop Runtime x64 설치
- [ ] Smart-81D 드라이버 설치 + USB 연결 + 전원 ON, 카드 호퍼 장착, YMCKO 리본 장착
- [ ] 배포 zip 압축 해제 (예: `C:\dalsu`) → `start-kiosk.cmd` 한 번 실행해 `npm install` 완료 확인 후 창 닫기

## B. 프린터 검증 (5분)
- [ ] `print-test.cmd` 실행 → "프린터 목록"에 Smart-81D 표시 (exit 0)
- [ ] **뒷면은 옵셋으로 미리 인쇄된 카드**를 쓴다(2026-09-06 확정). 앱은 **앞면만 단면 인쇄**한다(`card.printBack:false` 기본).
      호퍼에 카드를 넣을 때 **빈 면(앞면)이 인쇄 헤드 쪽**을 향하게 — 시험 카드 1장으로 방향을 확인한다(뒷면 디자인 위에 사진이 찍히면 뒤집어 넣는다).
- [ ] 시험 카드 1장 배출: 앞면에 사진+프레임(SAMSUNG 로고·달수)이 찍히고 뒷면 옵셋 디자인이 그대로인지. 로그에 `단면 인쇄 완료`.
      ⚠ 단면 경로(`dwPrtSide 0`)는 개발 PC 에서 실장비 검증이 **안 됐다** — 여기서 반드시 1장 뽑아 본다. (양면은 2026-09-01 실기 확인됨)
- [ ] 예전처럼 빈 카드에 양면을 뽑아야 하면 현장 `config.json` 에 `"card": { "printBack": true }` 를 적는다
- [ ] **가장자리 잘림 보정**(2026-09-07: SAMSUNG 로고 위·오른쪽 잘림): 현장 `config.json` `card.safeInset`(기본 0.025 = 전체를 짧은 변의 2.5% 축소, 테두리는 같은 그림으로 채움)과
      `card.printShift {x,y}`(기본 x:-5, y:5 px, +는 오른쪽/아래) 를 조절한다. 시험 카드에서 로고가 아직 잘리면 `safeInset` 을 0.03~0.04 로, 한쪽만 잘리면 `printShift` 를 그쪽 반대로 5px 씩.
      값은 앱 재시작 없이 다음 인쇄부터 적용된다(config 리로드는 재시작 필요 — 바꾸고 앱을 한 번 껐다 켠다)
- [ ] 리본 잔량 로그 확인 (`리본: type=0 잔량=n/max`) — 행사 3일 소요량(예상 발급 수 × 1.1) 이상

## C. 앱 설정 (`kiosk\config.json`)
- [ ] `printer.mode` → `"smart"`
- [ ] `printer.sdk` 는 `"comm"` 유지(기본). 면 설정은 로그의 `인쇄 면 설정` 줄로 확인(단면이면 값 0)
- [ ] `sound.enabled` true 면 대기 영상 소리(`sound.idleVolume` 0.6)·터짐 효과음(`sound.sfxVolume` 0.8)이 키오스크 스피커로 나간다 — 현장 볼륨 확인
- [ ] `comm` 으로 인쇄가 안 되면 `"dcl"` 로 바꿔 재시도하고, 어느 쪽이 됐는지 기록
- [ ] 프린터 2대 이상이면 `printer.deviceDesc`에 `--list`의 desc 일부 입력
- [ ] 웹캠 2대 이상이면 `camera.deviceId` 지정, `camera.mirror`는 현장 확인 후 결정
- [ ] 문구·타이밍(`screen`, `timing`) 클라이언트 확정본과 대조
- [ ] `screen.captureOverlay`는 `false` 유지(촬영 화면에 달수·물길을 겹치지 않음 — 사람 가림 방지). AR을 화면에도 겹쳐 보이려면 `true`

## D. 앱 E2E (10분)
- [ ] `start-kiosk.cmd` 실행 → 전체화면, 대기 화면에 **빨간 "프린터 미연결" 배너가 없어야 함** (배너가 뜨면 B로 복귀)
- [ ] 대기 화면: 타이틀 그래픽 + 물방울 3개(Reduce/Reuse/Restore) 부유 + **달수 대기 영상**이 소리와 함께 돈다(로그 `클라이언트 UI 자산 {idleVideo:true …}`)
- [ ] 물방울 3개 터치(순서 무관): 누르면 살짝 눌리고 떼면 터짐 → 문구가 그 자리에 남고 → 물 알갱이가 위로 모여 상단에 작은 물방울 3개
- [ ] 셋 다 터진 뒤 1.5초 → **물길 영상**(드롭 3개 → 합류 → S자 강 → 수달, 약 10초, 로그 `물길 영상 사용`) → "사진 촬영 준비해주세요!" → 3·2·1 → 촬영(플래시) → 미리보기
- [ ] 미리보기 중 카드 출력 시작, 앞면=사진+프레임 (뒷면은 옵셋 사전 인쇄)
- [ ] `out\<날짜>\card-*-front.png` 저장 확인, `logs\kiosk-<날짜>.log`에 "인쇄 완료"
- [ ] 60초 무조작 시 대기 화면 복귀
- [ ] **영상·연출이 끊기지 않는가** — 로그의 `그래픽 가속`(하드웨어/소프트웨어)과 `렌더 성능 {fps, step}` 확인.
      대기 영상(1080p)이 버벅이면 `scripts/import-client-assets.py` 로 720p 재인코딩 후 교체. 물길 영상이 없으면(`물길 영상 없음`) 예전 절차 연출로 자동 대체된다
- [ ] 프린터 커버 열고 1회 진행 → "직원을 불러주세요" 화면 + "처음으로" 버튼 동작 → 커버 닫고 정상 복구
- [ ] **숨김 종료**: 화면 오른쪽 위 모서리를 2초 안에 3번 터치 → 앱 종료 (운영자만 아는 탈출구, 화면에 표시 없음)
