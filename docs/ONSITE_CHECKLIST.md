# 현장 설치·검증 체크리스트 (Smart-81D 실장비)

개발 PC에는 프린터가 없어 **실장비 인쇄는 아래 절차로 현장(또는 사무실 프린터 연결 PC)에서 검증**합니다.
모든 항목을 체크한 뒤 운영에 들어갑니다.

## A. 설치 (10분)
- [ ] **설치형 사용**: GitHub Release 의 `DalsuARKiosk-Setup-X.Y.Z.exe` 실행(원클릭, 사용자별). 이후 새 버전은 대기 화면에서 자동 적용된다.
      설정·출력·로그는 `문서\DalsuARKiosk\` 에 생긴다 (config.json 도 여기). zip 으로 풀어 쓰면 자동 업데이트가 안 된다.
- [ ] 인터넷 연결 확인 (자동 업데이트용). 없어도 앱은 정상 동작 — 로그에 '업데이트 확인 실패'만 남는다.
- [ ] Node.js 22 LTS 설치 (`node -v`)
- [ ] .NET 8 Desktop Runtime x64 설치
- [ ] Smart-81D 드라이버 설치 + USB 연결 + 전원 ON, 카드 호퍼 장착, YMCKO 리본 장착
- [ ] 배포 zip 압축 해제 (예: `C:\dalsu`) → `start-kiosk.cmd` 한 번 실행해 `npm install` 완료 확인 후 창 닫기

## B. 프린터 검증 (5분)
- [ ] `print-test.cmd` 실행 → "프린터 목록"에 Smart-81D 표시 (exit 0)
- [ ] 시험 카드 1장 배출, **앞·뒷면 모두** 인쇄됨 (플리퍼 미감지면 로그에 "양면 모듈 없음" → 케이블/모듈 확인)
- [ ] 리본 잔량 로그 확인 (`리본: type=0 잔량=n/max`) — 행사 3일 소요량(예상 발급 수 × 1.1) 이상

## C. 앱 설정 (`kiosk\config.json`)
- [ ] `printer.mode` → `"smart"`
- [ ] `printer.sdk` 는 `"comm"` 유지(기본). 양면이 안 나오면 로그에서 `인쇄 면 설정: 적용 — dwPrtSide 0→2` 를 먼저 확인
- [ ] `comm` 으로 인쇄가 안 되면 `"dcl"` 로 바꿔 재시도하고, 어느 쪽이 됐는지 기록
- [ ] 프린터 2대 이상이면 `printer.deviceDesc`에 `--list`의 desc 일부 입력
- [ ] 웹캠 2대 이상이면 `camera.deviceId` 지정, `camera.mirror`는 현장 확인 후 결정
- [ ] 문구·타이밍(`screen`, `timing`) 클라이언트 확정본과 대조
- [ ] `screen.captureOverlay`는 `false` 유지(촬영 화면에 달수·물길을 겹치지 않음 — 사람 가림 방지). AR을 화면에도 겹쳐 보이려면 `true`

## D. 앱 E2E (10분)
- [ ] `start-kiosk.cmd` 실행 → 전체화면, 대기 화면에 **빨간 "프린터 미연결" 배너가 없어야 함** (배너가 뜨면 B로 복귀)
- [ ] 물방울 4개 터치 → 물길 → 자연 → 달수 이동 → 카운트다운 → 촬영(플래시) → 미리보기
- [ ] 미리보기 중 카드 출력 시작, 25초 내 배출, 앞면=합성 사진 / 뒷면=디자인
- [ ] `out\<날짜>\card-*-front.png` 저장 확인, `logs\kiosk-<날짜>.log`에 "인쇄 완료"
- [ ] 60초 무조작 시 대기 화면 복귀
- [ ] **물 연출이 끊기지 않는가** — 로그의 `그래픽 가속`(하드웨어/소프트웨어)과 `렌더 성능 {fps, step}` 확인.
      끊기면 앱이 스스로 단계를 내린다(`물 연출 N단계로 낮춤`). 그래도 끊기면 `config.river.quality`를 `"low"` 로 고정
- [ ] 프린터 커버 열고 1회 진행 → "직원을 불러주세요" 화면 + "처음으로" 버튼 동작 → 커버 닫고 정상 복구
- [ ] **숨김 종료**: 화면 오른쪽 위 모서리를 2초 안에 3번 터치 → 앱 종료 (운영자만 아는 탈출구, 화면에 표시 없음)

## E. 운영
- [ ] 시작프로그램에 `start-kiosk.cmd` 바로가기 등록, 전원 옵션 절전 해제
- [ ] 카드·리본 여분, 현장 담당자에게 `print-test.cmd`·"처음으로" 버튼 안내
- [ ] 행사 종료 후 `out\`, `logs\` 회수
